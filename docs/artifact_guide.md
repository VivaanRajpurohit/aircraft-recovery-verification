# Artifact guide

Tracked materials include source, tests, schemas, configurations, formal
specifications, small fixtures, manifests, and reproduction tools.

Excluded local artifacts include virtual environments, datasets, checkpoints,
raw histories, replay-session logs, raw verification grids, temporary plots,
screenshots, profiles, and unlicensed 3D models. These files remain in their
existing locations and are not deleted. Important local artifacts are indexed
by relative path, size, and SHA-256 digest in the artifact manifests.

Git LFS is not currently required: the public candidate files are small and
large generated or unlicensed artifacts are intentionally external.
