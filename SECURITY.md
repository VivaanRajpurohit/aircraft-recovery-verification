# Security and Safety

Report suspected credential exposure or unsafe external-control integration
privately to the repository owner through GitHub's private vulnerability
reporting feature. Do not include secrets in an issue.

This software must remain disconnected from real aircraft, drones, avionics,
actuators, external flight simulators, network-connected vehicles, and physical
hardware. The simulator and formal abstractions do not establish airworthiness.

Supported security fixes target the most recent tagged research protocol.
